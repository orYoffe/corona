Analysis scope & limitations

GitNexus call relationships are static analysis results; dynamic dispatch and runtime behavior may be missed. Files are grouped by path and positioned for legibility. 3D height maps to the selected metric: lines (including comments and blanks), direct importers, or named functions/classes. A minimum display height keeps zero-value files selectable; no complexity metric is inferred. No defect or risk score is inferred from size. Application source is unchanged.
